# M.D Forklift Cranes and Transport Services

Official website for **M.D FORKLIFT CRANES AND TRANSPORT SERVICES**, located in Narela Industrial Area, A Block Parking, Delhi, India.

Built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**, designed following the **UI/UX Pro Max** industrial design system framework.

---

## 🏗️ Core Business Services

- **Forklift Services**: Forklift equipment solutions for warehouse, industrial and material-handling requirements.
- **Crane Services**: Machinery and lifting service enquiries for industrial and construction requirements.
- **Heavy Equipment Handling**: Equipment handling solutions for moving and positioning heavy materials.
- **Transportation Services**: Transportation solutions for industrial equipment and material movement.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm start
```
